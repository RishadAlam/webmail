# WebMail logo prompt

The user approved the connected W-and-envelope concept on November 1, 2026. The identity is now installed throughout the application. Use [the existing brand assets](BRANDING.md) for implementation; the prompt below is retained as the original design brief.

Copy this prompt into a design or image-generation agent. It requests concepts and assets, not a change to the running application.

```text
Create an original professional logo for “WebMail”, with an optional secondary byline “by Hookstack”. WebMail is a private, self-hosted webmail application for small teams. Its personality is calm, clear, dependable and approachable. It has a practical inbox interface with light and dark themes.

Explore three distinct concepts, then recommend and refine the strongest one. Use a simple geometric symbol that subtly combines a W, a folded message or a connection between people. Avoid a generic stock envelope. The mark must remain recognizable at 16, 24 and 32 pixels and work without the wordmark.

Use restrained blue (#0B57D0) as the primary brand color, with a light blue (#A8C7FA) version for dark surfaces. Also supply monochrome black and white versions. Keep the symbol legible in one color so it works with the app’s teal, green, clay, plum and graphite themes. Pair it with a clean, carefully spaced wordmark. Make “WebMail” readable; “by Hookstack” is a smaller optional endorsement, omitted at small sizes.

Do not copy Gmail, Google’s multicolor M, Outlook or another mail brand. Avoid gradients, shadows, 3D effects, tiny details, shields, padlocks and claims such as “end-to-end encrypted” or “100% secure”. Present flat artwork on plain light/dark backgrounds, not device or stationery mockups.

Deliver an icon-only mark, horizontal wordmark, optional endorsed lockup, light/dark/monochrome variants, and transparent PNG exports. If you can author real vector geometry, include clean editable SVG files with outlined lettering, no embedded raster images, scripts or external resources; do not rename or trace a low-resolution bitmap and call it vector. Include 16/32 px favicon previews, 180 px Apple touch icon, 192/512 px PWA icons, and a separate maskable PWA version with the essential artwork inside the central 80%-diameter safe circle. Use opaque backgrounds for app icons and transparency for standalone marks.

Add a short brand sheet listing colors, typography/font licensing, minimum sizes and clear space. Show the 16 px mark before approving the final concept. Save assets for review; do not replace the application’s current icons or publish anything automatically.
```
